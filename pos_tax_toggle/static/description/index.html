Frequently Asked Questions (FAQ)

How does this module improve Odoo POS tax configuration?
By default, Odoo Point of Sale limits your manual price entries to either strictly tax included or tax excluded based on the company's fiscal settings. The POS Tax Toggler app allows cashiers to instantly switch between modes using a convenient UI toggle switch. This is incredibly useful for retail environments in regions like the UAE (VAT) or Europe, where some customers expect B2B (tax excluded) pricing and others expect B2C (tax included) pricing.
Does the toggle recalculate the price instantly?
Yes! As soon as you flip the switch from Tax Included to Tax Excluded, the Point of Sale line recalculates the exact base price and tax breakdown in real-time. It seamlessly handles rounding accuracy using your Odoo currency decimal places to prevent penny rounding errors.
Which Odoo versions is POS Tax Toggler compatible with?
This module is fully compatible with the new Owl framework used in modern Odoo Point of Sale versions (Odoo 17, 18, and 19). It integrates natively without heavy overrides, ensuring flawless compatibility with other POS apps.
